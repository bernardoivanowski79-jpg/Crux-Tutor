# Crux Tutor

Crux Tutor is an intelligent, AI-powered educational application designed to help students learn, revise, and track their academic progress using personalized lessons, quizzes, and study routines.

## 🚀 Features

* **AI-Generated Lessons & Quizzes:** Utilizes the Google Gemini API to create dynamic, tailored study materials, open questions, and quizzes across various subjects.
* **Curriculum & Grade Tracking:** Allows students to log their subjects, current grades, and specific topics to review.
* **Study Shifts & Notifications:** Set your preferred study shift (Morning, Afternoon, Full-time, Night) and receive customized daily notifications with your review plan.
* **Multi-Language Support:** Choose between English, Portuguese, and Spanish interfaces directly from the login/profile screens.
* **Modern UI:** Built fully with Jetpack Compose featuring adaptive light and dark themes using Material Design 3 guidelines.
* **Offline Progress:** Uses local Room Database to save chat history, generated quizzes, past lessons, and academic progress.

## 🛠️ Tech Stack

* **Language:** Kotlin
* **UI Toolkit:** Jetpack Compose (Material Design 3)
* **Architecture:** MVVM (Model-View-ViewModel) + Clean Architecture principles
* **Local Storage:** Room Database, SharedPreferences
* **Asynchronous Programming:** Kotlin Coroutines & StateFlow
* **AI Integration:** Google Gemini API

## 🔑 Setup

To run the application with full AI capabilities, you need to configure your Gemini API Key:
1. Open the app.
2. Go to your **Profile** or click the settings icon.
3. Select **Google Gemini API** and insert your valid API Key.

## 📱 Screenshots & Assets
The app includes dynamic custom vector avatars and responsive 3D banners seamlessly integrated into the user interface for a premium look and feel.

## 🛡️ Privacy
Crux Tutor stores all study data, grades, and chat history locally on your device ensuring maximum privacy.
